📥 Import Data Peserta (Excel)

Import peserta massal dari file Excel (.xlsx). Tanpa batas jumlah. Semua peserta wajib punya data diri lengkap dan berstatus Menunggu Verifikasi.

⚠️ Import TIDAK dibatasi kuota peserta. Nominal pembayaran = jumlah peserta × harga satuan.

📋 Cara Import:

  1. Klik Download Template Excel di bawah
  2. Isi baris data peserta di tabel template (jangan hapus header)
  3. Simpan sebagai .xlsx atau .xls
  4. Klik Pilih File Excel untuk upload
  5. Periksa preview → klik ✅ Import

• Ukuran kaos: S, M, L, XL, XXL, XXXL

• Format tanggal: YYYY-MM-DD, waktu: HH:MM

• Nomor WhatsApp harus unik
